# 输入操作与资源配置

所有聊天修改先校验，回复后点击“应用到场景”。窗口只显示简短说明，隐藏候选配置 JSON。单位坐标和间距单位为米；新建编组时各单位沿 Y 方向按间距排列，人工编辑后每架单位独立保存位置和朝向。航迹保存有序航点并显示连线，单位保持静止。

## map3 场景（2026-10-16）

启动仍进入机场。在对话框输入“切换到map3场景”，收到回复后点击“应用到场景”；返回时输入“切换到机场场景”，再点击应用。切换前请保存需要保留的编辑方案。

map3 使用独立初始方案：3架 J20_Map3 属于“编队1”，3架 F35 属于“编队2”，默认在山地上方保持静止。两种模型来自本次提供的 Move 场景，位于 Content/plane；机场继续使用已有 J20/J10。进入后自动取景；“加载原始配置”恢复当前地图的初始编队。

右侧“播放轨迹”启动运动预览，相机跟随当前选中单位所在编组；在单位列表选择另一编组的成员可切换观察。“停止轨迹并复位”或 Esc 返回编辑位置和原视角。打开单位编辑窗口、应用修改、重载或清空场景也会结束预览。保存方案保存编辑状态，不保存播放进度。编队可以先排列、修改，再播放；播放时不支持直接拖动飞机。机场和其他地图也可播放已编辑的航迹；没有可用航迹时会提示先到航迹页应用航点。

轨迹来自原UE工程的两条闭合样条，每条257个采样点，采用40秒演示周期。每组以当前首架为起点，沿源轨迹相对位移运动，其余飞机保留相对队形并随航向转动。这是轨迹演示，不包含碰撞、避障、气动力或原蓝图完整运动逻辑。

山地及两种飞机已使用补充提供的原始材质/贴图；Landscape1仍使用基础地形材质，原天气插件、导弹与游戏BP未迁入。FBX原件保留在 `Content/Maps/map3.fbx`。材质及贴图保留在Content/Airfight以维持原资源引用。

## 飞机头顶机型标牌（2026-10-20）

进入场景后，每架运行时飞机自动显示机型标牌：J-20、J-10、F-35。原机场J20与新导入的J20_Map3均显示J-20；基础占位模型显示“飞机”，其他登记机型显示模型名称。机型替换或加载方案后自动更新；资源回退为占位模型时显示实际回退身份，不继续显示缺失机型。

标牌为深色底，J-20、J-10文字为粉红色（#FF80BF），其他机型文字为白色；保持固定屏幕尺寸并始终正对镜头。位置在飞机网格顶部上方，邻近标牌会尝试上下及横向错开并保留指示线。相机背后及屏幕外的飞机不绘制标牌。标牌位于控制面板下层，不拦截鼠标，不改变选中框、碰撞、模型或原材质。

拖动、批量编辑和航迹预览时，标牌跟随当前显示的飞机；预览不会在原位置残留另一份标牌，停止后随飞机回到编辑位置。显示根据当前场景自动生成，不需要另行保存到方案，也不会产生撤销记录。

维护验收：Scripts/TestNameplates.ps1在机场和map3核对6个实际绘制标牌、四种现有机型及移动/复位截图，证据在Saved/Nameplates。

## 飞机发光高亮（2026-10-19）

在右侧单位列表选中一架飞机，在聊天框发送“让选中的飞机高亮”，收到候选后点击“应用到场景”。也可以指定本场景的完整飞机编号；“查看飞机编号”会列出可用编号。一次只操作一架，可逐次开启多架。

```text
让选中的飞机高亮
取消选中的飞机高亮
让 RED01_001 发光高亮
取消 RED01_001 高亮
高亮帮助
```

机场通常使用RED01_001等编号，map3使用RED01_1等编号，请以当前列表为准。未知编号、非飞机、多目标或混合操作不会生成修改；不支持通过聊天修改发光颜色。

效果是固定金色的发光叠加层，不替换原材质或贴图，不改变阵营、位置、朝向与编队。关闭后恢复原外观。打开“单位编辑与方案管理”可撤销、重做；在“方案库”另存后，高亮状态随方案保存和加载。旧方案没有高亮字段时默认关闭。

点击选中现在也会临时发光。手动关闭保存的高亮后，若飞机仍被选中，临时选择高亮会继续显示；点击空白取消选择即可消失。临时选择不会写入方案或撤销历史。

高亮指令在本地处理，无需连接Qwen。map3轨迹预览继承已开启的高亮，停止后保留编辑状态；在预览中应用高亮修改会先停止预览。效果亮度受当前视角与渲染设置影响，属于显示强调，不会增加照亮周围场景的灯光。

维护：材质路径在Config/DefaultGame.ini的HighlightMaterialPath，默认/Game/Materials/M_AircraftHighlight。新材质由Scripts/CreateHighlightMaterial.py生成，脚本保留已有资产。构建后可运行Scripts/TestHighlight.ps1验收机场和map3的真实窗口，日志与截图在Saved/Highlight。

## 单位编辑与方案管理（2026-10-12）

右侧点击“单位编辑与方案管理”，打开编辑与方案窗口。右侧内容支持滚动。

窗口现分为“单位、编队、方案库、航迹”四个页签。位置与朝向在“单位”页，保存、加载及文件导入导出在“方案库”页；底部撤销、重做对单架/批量编辑、成员调整、整队排列和航迹编辑均有效。

窗口可以浮动：左键按住顶部“场景编辑”标题栏拖动，松开停下。输入框、页签及关闭按钮不会启动拖窗；窗口移动范围限制在画面内。关闭后再次打开保留本次运行中的位置，重新启动程序时恢复默认居中位置。拖动窗口不会移动飞机或改变场景配置。

1. 点击一架飞机单选，Ctrl＋点击增减多选，点击空白清空选择。所有被选飞机会临时发光；最后加入的飞机为主选。右侧单位列表和编辑窗口的单位下拉框用于单选；单位页也有“全选飞机”“清空多选”。
2. 单位页显示当前选择数量及主选编号。填写 X、Y、世界 Z（米）和朝向，点击“应用到当前单选 / 多选”。多选时以主选飞机为基准整体平移，保留相对位置；朝向采用共同角度差，不旋转队形位置。填写新名称后点“用当前多选建立编队”，会将所选飞机组成新编队，可跨阵营/机型，已有同名编队会被拒绝。
3. 多选后松开Ctrl，再按住已选飞机拖动，可整体移动当前选择；松开提交，Esc取消，右键观察也会取消未提交拖动。在已选飞机上单击而未拖动会恢复为单选。拖动沿主选高度的水平面，不自动贴地；一次批量操作只需一次撤销。
4. 打开窗口点击“撤销”或“重做”，可恢复位置及朝向编辑。加载、清空或聊天应用完整新场景后，旧编辑历史清空。
5. 填写名称并点击“另存为新方案”。名称重复时需要换一个新名称，不会覆盖已有方案。
6. 在方案列表选中名称，点击“加载选中方案（包含地图）”。不同地图会先切换地图，再恢复方案；缺失地图、型号或贴图会在应用前拒绝。
7. 导出：选择方案，填写新的 `.json` 文件完整路径，点击“导出选中方案”。目标目录需要存在，不覆盖已有文件。
8. 导入：填写已有 `.json` 文件完整路径及新方案名称，点击“导入到方案库”。名称留空时使用文件名；导入只加入列表，点击加载才改变场景。旧格式场景配置也可以导入；无地图字段时使用加载时的当前地图。

### 航点列表编辑（2026-10-19）

先单选或多选飞机，再打开“航迹”页。表格采用世界坐标 X/Y/Z（米），可修改任意一行、添加航点或删除末点，设置时长及是否闭合循环，再点击“应用所选飞机航迹”。多选时以主选为参考，将同一航迹按每架当前相对位置平移，保持队内间距。应用只保存配置，飞机仍静止；关闭编辑窗口后点击右侧“播放轨迹”预览。

航迹优先读取单机已保存航迹，其次原编组航迹，再次读取适配的map3源航迹；无来源时显示从当前位置出发的100米直线草稿，需手动应用。map3源航迹可完整载入表格编辑。开放航迹支持2至512点，到达末点后保持；闭合航迹至少三个不同点，自动补回起点，总点数不超过512。开放时长包含飞向首点的接入段；闭合时长为每圈，首次接入另计。开始播放不会瞬移，停止恢复编辑位置。

输入只改草稿，蓝线和青色点只在当前航迹编辑视图预览。选择或场景改变后，未应用草稿会保留，但禁止应用到新目标；点击“重新读取所选航迹”后重新编辑。“恢复所选默认航迹”移除所选飞机的自定义航迹，恢复原编组/map3来源；没有默认来源时需重新创建。每次应用或恢复均可整体撤销，并可随方案保存。普通聊天修改保留自定义航迹；明确修改编组航迹时，会移除匹配飞机的自定义覆盖以采用新航迹。

维护验收：Scripts/TestSelectionAndRoutes.ps1在机场和map3检查拾取、多选高亮、直接编队、批量编辑及撤销、航迹表格应用、保存和实际播放。证据在Saved/MultiSelection。选中状态不保存；源地图、原始飞机和Map3FlightPaths.json不被编辑器改写。

方案保存在工程内的 `TacticalDemo/Saved/Scenarios`，重启后保留。方案包含地图、稳定单位编号、编组关系、型号、贴图、每架位置与朝向和静态航迹。它是可复用配置，还不是模型训练样本。

坐标 Z 是世界高度，不是离地高度。朝向绕世界 Z 轴旋转，0°保留模型导入时的原始方向。单架朝向通过编辑窗口调整，整队朝向也支持下方聊天指令。原机场布景不属于可编辑单位。

人工编辑会更新聊天所依据的当前场景，并取消旧候选和旧请求。后续模型、贴图、阵营或航迹修改保留各架位置与朝向；编组位置指令整体平移，间距指令重新排列该组 Y 坐标，减少数量保留前面的单位，增加数量保留原单位并补充新单位。

## 自由编队与排列（2026-10-12）

1. 打开“编队”页，选择“编队1”或“编队2”。也可在成员编辑区填写新的名称，最长32个字符。
2. 点击“选择或修改成员”，勾选需要加入的飞机，点击“保存勾选成员”。可跨阵营、跨型号选择；每架飞机只属于一个编队，转入新编队时从旧编队移除。取消全部勾选并保存可清空该编队。
3. 保存后成员列表收起。选择横排、纵列或楔形，填写起点X/Y、间距和方向，点击“排列当前编队”。成员有未保存的改动时会提示先保存。
4. 各架飞机保留当前世界高度，朝向设为输入角度；首架以当前场景列表顺序确定，放在起点，其余依次排列。方向0°采用世界+X为编队前向，90°为世界+Y；模型机头仍取决于导入轴向。
5. 横排沿编队右向排列，纵列向首架后方排列；楔形在首架后方交替分配左、右翼。楔形“间距”是每层后退及向外展开的距离，相邻翼位的直线距离不等于该数值。
6. 点击一次“撤销”即可恢复整次排列。到“方案库”另存方案后，编队名称、成员和位置一起保存，重启加载仍可继续排列。

编队也可通过聊天创建和管理（2026-10-16）：机场初始没有编队时，可直接输入“把红方飞机编成编队3”，点击“应用到场景”后生效。每条指令执行一个操作；成员管理、排列、移动、高度、朝向都生成候选，手动应用后可通过窗口撤销和重做。替换型号、贴图、阵营后保留已有编队成员；新增飞机默认未分配编队。当前排列不自动避障、贴地或检查安全间距；飞机保持静止。

成员可按阵营、当前机型、单位组编号或飞机实际编号选择，也可用“编队1成员”选择已有队员。机型按当前配置区分：`J20` 是原机场模型，`J20_Map3` 是新导入模型；`F35`/`F-35`均可。输入“查看飞机编号”获取本场景实际编号；指定多架时用顿号分隔。混合选择中任一项不存在就拒绝整条指令，不会仅应用其中一部分。

“编成”创建新编队，名称重复时拒绝；向已有编队补充飞机请用“加入”。每架飞机只属于一个编队，转入时会在候选说明中列出转入数量。“移出”仅解除所选飞机与指定编队的关系；“解散”解除全队归属，保留所有飞机。成员管理保持型号、数量、位置及朝向不变。自然语言名称支持1至32个中文、字母、数字、下划线或连字符；复杂复合指令请分开发送。

需要重启后继续使用时，在“单位编辑与方案管理 → 方案库”另存方案，重启后加载；仅点击应用不会自动覆盖初始配置。输入“编队帮助”可随时查看示例，未连接Qwen也可使用这些编队指令。

### 可直接粘贴的编队指令

每次发送一行，修改指令收到候选后先点击应用。以下为独立示例，目标成员和已有编队应按当前场景选择：

```text
编队帮助
查看飞机编号
把红方飞机编成编队3
把蓝方飞机加入编队3
把蓝方飞机移出编队3
把编队3改名为护航编队
解散护航编队
当前有哪些编队
显示编队列表
调用编队1
查看编队1成员
把编队1排成横队，间距35米
把编队2排成纵队，间距35米
把编队1排成V形，间距35米，方向90度
把编队1整体移动到X=550米、Y=-515米
把编队1高度改为30米
把编队1朝向改为90度
```

横队等同横排，纵队等同纵列，V形/V字形/人字形等同楔形。未指定排列参数时，起点为首架当前位置、间距35米、方向为首架当前朝向；可指定“起点X=550米、Y=-515米”。整体移动保留队内相对位置、高度和朝向。高度为绝对世界Z坐标，不是离地高度；朝向只转动每架飞机，不旋转整队的位置布局。查询、调用不修改场景。这些编队指令由本地规则解析，不依赖Qwen服务连接。

维护验收：`Scripts/TestFormationLanguage.ps1` 依次在机场和map3验证聊天创建、手动应用、排列、撤销重做及实际渲染截图；可用 `-Scene airport` 或 `-Scene map3` 单独运行。结果保存在 `Saved/FormationLanguage`；运行前先构建最新代码。

“只把红方……”限定原有阵营；“飞机全部……”限定单位类型。数量为0可以移除匹配组的实体。当前不支持按单个单位 ID 的自然语言选择。“创建新场景”替换当前地图中的单位配置；“切换到机场场景”才切换背景地图。修改指令保留未提及内容。模型库包含真实 J20、J10 及圆锥、方块、圆柱、球体占位资源。
