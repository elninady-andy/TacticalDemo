# 窗口与对话（取代本轮 window-motion 计划）

用户本轮明确以窗口与对话为主；不实现阵型/航点运动。沿用已授权的 UE 内嵌窗口方向。

- C++ UMG：左侧聊天历史、输入/发送；中间现有地图；右侧单位列表和位置；底部加载原始配置、应用候选、清空、取景。
- 异步 HTTP 调用本地 Qwen 的 OpenAI 兼容接口，地址与模型可配置；缺少设置时明确提示，不伪造回复。不重新部署模型。
- 模型输出 reply 和可选 scenario。场景只使用已支持字段，经过现有严格解析后才成为候选；点击应用调用现有事务加载。保留原始 Scenario.json，候选写入 Saved。
- 普通聊天不生成场景；失败保留原场景，发送期间防重复，可取消。窗口销毁取消请求；上下文有上限。
- 默认显示鼠标，按住右键进入观察模式，避免打字触发场景快捷键。
- 测试解析有效回复、非法/越界场景、纯聊天、接口错误及实际渲染。模型真实端到端测试依赖用户提供已有接口。

本设计遵循用户“继续执行”及本轮范围修正，不增加审批步骤。尚无 Git 仓库。
