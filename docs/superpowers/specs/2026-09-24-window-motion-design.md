# 第二阶段：控制窗口、编队与航点运动

用户要求：为当前版本添加窗口并继续下一阶段。沿整体路线实施，默认在 UE 游戏窗口内加入 UMG 控制面板，复用现有项目与文件协议。

## 交付
- C++ 构建的 UMG：顶部场景名/状态/时间，左侧配置路径和加载，右侧单位选择和参数，底部重载/开始/暂停/重置/清空/取景。
- 默认显示鼠标操作面板；按住鼠标右键进入飞行观察，松开恢复界面操作。
- Line/V/Triangle 编队、speed 和 route，提供可直接运行的示例。
- 保留无新字段的旧 JSON；默认 Line、speed=0、route=[]。

## 配置及编队
formation 必须为 Line、V 或 Triangle；speed 为有限 0～10000 米/秒；route 为最多 32 个 {x,y,z} 米制点，允许空路径。所有原始位置及偏移后路线均在 ±1000000 米内。

Line 保持旧行为：(0,index*spacing,0)。V 以第一台为领队，依次为 (-s,-s,0)、(-s,+s,0)、(-2s,-2s,0)、(-2s,+2s,0)。Triangle 按行填充：行 r 有 r+1 台，偏移 (-r*s,(列-r/2)*s,0)。数量不限于恰好三台，仍受每组 100 限制。

position 为领队初始位置，route 是领队绝对航点；每个单位沿 route+自身偏移行进。编队偏移固定在世界 XY 平面，转弯不模拟真实飞行动力学。不使用速度插值或路径寻路，按每帧可走距离依次消耗线段，处理重复点、大时间步和终点停止。

## 状态与可靠性
Empty/Ready/Running/Paused/Completed 五种状态。加载成功进入 Ready（空数组为 Empty），开始进入 Running；暂停保持位置与累计时间；重置复原当前已加载内容并归零，不重新读取磁盘。全部可运动单位到达终点后 Completed，再次运行需 Reset。无路线或零速度的单位保持静止。

只有 Manager Tick 推进运动；不暂停整个 World，保证相机和界面可用。失败重载保留当前实例、运行状态及计时。Load 支持输入 JSON 路径（相对路径相对 Config 目录），Reload 使用最近成功加载路径；模型库仍使用当前工程配置。

## 代码边界
- FormationHelper：纯偏移计算。
- ScenarioConfig/Loader：增加字段及严格校验。
- DemoUnitActor：保存初始位置、单位路线及运动进度，提供 AdvanceMotion/ResetMotion。
- DemoScenarioManager：运行状态、时间、开始/暂停/重置、统一 Tick。
- DemoControlWidget：控件创建、按钮绑定、状态/参数展示；不维护第二份场景状态。
- DemoGameMode/PlayerController：面板挂载、鼠标模式、取景（包含路线范围）。

## 验收
新增字段非法输入必须失败且不破坏原场景。编队位置用固定预期值验证；运动验证单位转换、跨越多点、重复点、终点停止；状态验证开始/暂停/恢复/重置/清空及运行中坏重载。回归原四项测试。真实渲染检查面板、中文、可见单位及路线；交互验证按钮绑定和状态变化。增量编译，更新 MAP/STATUS 和使用说明。

本阶段不接入 Qwen、不新增雷达或武器，也不做打包发布。
